# Luna·nara Coffee & Craft — QR Menu

Mobile-first static website with 7 menu category pages and a welcome page.

## Deploy to Vercel
1. Upload all files and the `assets` folder to the **root** of your GitHub repository (not the ZIP file).
2. In Vercel, import the repository. Choose **Framework Preset: Other**, leave **Build Command** empty and **Output Directory** empty/default, then deploy.
3. Use the deployed domain as the URL for your table QR codes.

## Edit
- Prices and drink names: `app.js` (`categories` data)
- Colors/layout: `style.css`
- Background: `assets/celestial-background.webp`
- Site works without a build step.

Check package and discount terms with cafe staff before publishing.
